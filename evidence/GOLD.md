# Gold(정답) 작성 규약 — 동결 2026-10-30

- 작성자: Claude(AI). **사람 검산이 아니다.** 소스 파일을 직접 열어(grep·줄 읽기) 판정했고, 도구 판정(`scan`)을 **보기 전에** 이 파일을 동결·커밋했다(커밋 메시지에 「Gold 동결」). 사용자 재검산은 대기 중이며, 재검산 결과가 다르면 이 표를 고치고 일치율을 다시 낸다.
- 경보 목록은 `evidence/alerts/*.json`(판정 없는 SBOM+OSV 결과)에서 골랐다. 고르는 기준: 저장소마다 도달·사용·미확인이 섞이도록, 직접 의존과 전이 의존이 섞이도록. 도구가 틀릴 만한 경우(인스턴스 메서드 호출, 설정으로 로딩, 주 진입점)를 일부러 포함했다.
- 분류 정의
  - REACHED(도달): 저장소 코드가 어드바이저리가 지목한 취약 함수·속성을 호출·참조하거나, 어드바이저리가 함수를 특정하지 않은 단일 주 진입점 라이브러리(marked() 등)의 그 진입점을 호출한다. 인스턴스 메서드·속성(res.redirect, request.body)도 사람이 읽으면 도달로 본다.
  - USED(사용): 저장소가 그 패키지를 쓰지만(import 또는 설정 로딩) 어드바이저리가 지목한 취약 기능은 호출하지 않는다.
  - UNSEEN(미확인): 저장소 소스에 그 패키지를 쓰는 줄이 없다. 전이 의존이 다른 패키지를 통해 실행될 수는 있다 — 「안전」이 아니다.
- 한계: 66건은 한 사람(AI)의 판단이며 저장소 4곳에서 골랐다. 정답이 애매한 경보(함수를 특정하지 않은 어드바이저리)는 일부러 적게 넣었다.
